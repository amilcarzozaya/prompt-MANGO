# Referencia rápida multimodal — Prompt MANGO

## Imagen
Además de MANGO, revisar: sujeto, escenario, acción, composición, cámara, lente si aplica, iluminación, estilo, materiales, paleta, atmósfera, aspect ratio y negativos/restricciones.

## Video
Además de MANGO, revisar: duración, escenas, continuidad, acción por escena, cámara, ritmo, transiciones, audio/diálogo, aspect ratio y restricciones del generador.

## Música
Además de MANGO, revisar: propósito, género, emoción, tempo, instrumentación, estructura, duración, voz/instrumental, idioma, producción y plataforma destino.

## Regla de portabilidad
No usar sintaxis propietaria de una plataforma salvo que el usuario indique explícitamente el modelo destino. Si lo hace, adaptar el prompt sin perder la estructura conceptual MANGO.
